# Obesity-Level-Prediction
Machine Learning project for predicting obesity levels using classification algorithms and Python.

🏥 Obesity Level Prediction using Machine Learning
📌 Project Overview

This project predicts obesity levels based on an individual's lifestyle habits, eating patterns, and physical characteristics using Machine Learning. A Logistic Regression model is trained to classify individuals into different obesity categories.

🎯 Problem Statement

The objective of this project is to develop a machine learning model that predicts obesity levels using demographic, physical, and lifestyle-related features.

📊 Dataset Information

The dataset contains information such as:

Gender
Age
Height
Weight
Family History
Eating Habits
Physical Activity
Water Consumption
Smoking Habit
Technology Usage
Transportation Mode

Target Variable: Obesity Level
